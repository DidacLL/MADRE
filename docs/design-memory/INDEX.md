# Design Memory

No active design-memory notes are retained for the Security Algebra, SDK, CORE, or
execution architecture.

Their valid owner-native conclusions have been incorporated into `MADRE.md` and the
focused documents under `docs/architecture/`. Superseded generated designs remain
available through Git history and must not be reconstructed as compatibility
requirements or parallel authority.

New design-memory notes should be added only when a still-useful rationale cannot be
expressed more directly in the product contract, focused architecture, executable
code, or tests.
