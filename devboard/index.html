Repository Governance

  • Work branch required for non-trivial changes.
  • PR integration expected before `main`.
  • CI required before merge.
  • `main` is not the normal work branch.

Artifact Ownership

  • agents/def/**: stable procedure only.
  • docs/technical/**: technical contracts.
  • agents/state/**: advisory state.
  • agents/reports/** or agents/backlog/**: generated analysis and reports.

Implementation Readiness Gates

Definition Owned behavior has an accepted product or technical definition.
Slice First-slice scope and explicit non-goals are named.
Evidence Expected trace records and acceptance evidence are defined.
Negative path At least one unsafe or unsupported path must fail safely.
